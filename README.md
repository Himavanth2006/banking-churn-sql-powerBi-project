# Banking Customer Churn Analysis

## Project Overview

This project analyzes customer churn in a banking dataset using SQL and Power BI. The objective is to identify factors influencing customer attrition, uncover churn patterns, and provide actionable business insights to improve customer retention.

## Tools Used

* SQL
* Power BI

## Dashboard KPIs

* Total Customers: 10,000
* Churned Customers: 2,037
* Churn Rate: 20.37%
* Average Balance: 76.49K

## Analysis Performed

* Customer churn analysis by gender
* Churn analysis by age group
* Product-wise churn analysis
* Geography-wise churn analysis
* Customer balance analysis
* Customer segmentation using SQL queries
* Interactive dashboard creation in Power BI

## Business Impact

* Identified customer segments with the highest churn risk.
* Analyzed churn patterns across age, gender, products, and geography.
* Highlighted opportunities for customer retention and cross-selling.
* Provided data-driven insights to support strategic decision-making.
* Developed an interactive Power BI dashboard for business reporting and analysis.

## Key Findings

* Overall customer churn rate is approximately 20%.
* Customer churn varies significantly across demographic groups.
* Geographic location plays an important role in customer retention.
* Product ownership and account activity influence customer loyalty.
* Customer behavior patterns can be used to identify high-risk churn segments.
